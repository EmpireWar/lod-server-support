# LSS 0.16.0 release preparation

Prepared 2026-09-29 UTC (September 28 locally). **Local preflight passed on all five maintained lines.** No new runtime blocker was found. Release branches, exact-version artifacts, release notes and a publication manifest are ready for review. Branch pushes, remote CI, merges, tags and publication remain the release step; none was performed during preparation. VSS remains excluded from publication.

Read the [proposed notes](release-notes-v0.16.0-proposed.md) and [machine-readable release manifest](../implementation/2026-09-29-v0.16.0-release-preparation.json). The per-line tag notes explicitly preserve each platform's shipping and renderer capabilities.

- All 30 release jars retain the exact class bytes, private SQLite payloads and settings templates from the previously reviewed development jars. The versioned outer metadata and filenames change as expected. Exact archive hashes are retained separately.
- Both reported SQLite collision stacks already passed independently valid NeoForge boots and real store write/restart/read tests. Representative packaged Fabric/Paper checks and Windows Java 21/25 SQL probes also passed. Those native runs used the preceding development jars, whose production class/private-resource bytes match the versioned release jars; they are not relabeled as new 0.16.0 live runs.
